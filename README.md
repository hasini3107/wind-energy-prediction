# 📖 Overview

Wind energy is one of the fastest-growing renewable energy sources. However, its power generation depends on varying weather conditions. This project uses Machine Learning techniques to predict wind energy output based on historical meteorological data.

The prediction system helps improve renewable energy utilization by enabling better planning, scheduling, and energy management.

# 📈 Model Evaluation

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/hasini3107/wind-energy-prediction.git
```

Go to the project directory

```bash
cd wind-energy-prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

